# MedCheck · เว็บไซต์อ่านฉลากยาสามัญประจำบ้าน

ปริญญานิพนธ์ สาขาวิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยรังสิต ปีการศึกษา 2569

ผู้ใช้งานถ่ายภาพฉลากยาสามัญประจำบ้าน ระบบอ่านข้อความด้วยเทคโนโลยีการรู้จำอักขระด้วยแสง
แล้วจับคู่กับข้อมูลยาในระบบ เพื่อแสดงข้อบ่งใช้ ขนาดการใช้ และคำเตือน

## โครงสร้างที่เก็บโค้ด

```
medcheck/
├── frontend/          ส่วนติดต่อผู้ใช้งาน · HTML + CSS + JavaScript ล้วน ไม่ใช้เฟรมเวิร์ก
│   ├── index.html     หน้าเดียวครอบทุกหน้าย่อย สลับด้วยเส้นทางแบบ hash
│   ├── css/           tokens · base · shell · components · pages (ลำดับการเรียกสำคัญ ห้ามสลับ)
│   ├── js/data.js     โหลดและค้นข้อมูลยา
│   ├── js/app.js      ควบคุมหน้าจอทั้งหมด
│   └── data/drugs.json  ข้อมูลยาที่ใช้แสดงผลในปัจจุบัน
└── backend/           ส่วนประมวลผล · FastAPI + SQLAlchemy + PostgreSQL (Neon)
    ├── main.py        เส้นทางของ API
    ├── models.py      ตารางทั้ง 7 ตาราง
    ├── matcher.py     จับคู่ยาจากข้อความที่อ่านได้ 3 ลำดับ
    ├── database.py    การเชื่อมต่อฐานข้อมูล
    └── ocr_test.py    ทดสอบ Google Cloud Vision แยกจากตัวระบบ
```

## การแบ่งงาน

| ส่วน | ผู้รับผิดชอบ | กิ่งที่ใช้ |
|---|---|---|
| ส่วนติดต่อผู้ใช้งาน | ภูทิตา | `frontend` |
| ส่วนประมวลผลและฐานข้อมูล | เพื่อนร่วมทีม | `main` |

## วิธีรันส่วนติดต่อผู้ใช้งาน

ไม่ต้องติดตั้งอะไร แต่ต้องเปิดผ่านเซิร์ฟเวอร์ ห้ามดับเบิลคลิกไฟล์
เพราะเบราว์เซอร์จะไม่ยอมให้อ่านไฟล์ข้อมูลยา

```bash
cd frontend
python -m http.server 8130
```

เปิด http://localhost:8130 หรือใช้ส่วนขยาย Live Server ของ VS Code ก็ได้

## วิธีรันส่วนประมวลผล

ต้องมีไฟล์ 2 ไฟล์ที่ไม่ได้อยู่ในกิต ขอจากผู้รับผิดชอบส่วนนี้

```
.env                       ที่อยู่ฐานข้อมูลและที่อยู่ไฟล์กุญแจ
otc-senior-project.json    กุญแจบัญชีบริการของ Google Cloud
```

```bash
cd backend
python -m venv venv
venv\Scripts\activate          # Windows · macOS กับ Linux ใช้ source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

เปิด http://127.0.0.1:8000/docs เพื่อดูและทดลองเรียกเส้นทางทั้งหมด

## เส้นทางของ API

| เส้นทาง | วิธี | หน้าที่ | สถานะ |
|---|---|---|---|
| `/medicines/search?name=` | GET | ค้นหายาจากชื่อ | ใช้งานได้ |
| `/medicines/by-category?category_id=` | GET | ค้นหายาจากกลุ่มอาการ | ใช้งานได้ |
| `/medicines/{id}` | GET | ข้อมูลยาแบบเต็ม | ใช้งานได้ |
| `/scan` | POST | รับภาพฉลาก อ่านข้อความ แล้วจับคู่ยา | ยังไม่ได้ทำ |

### สัญญาของเส้นทาง `/scan`

ส่งไฟล์ภาพด้วย `multipart/form-data` ชื่อช่องว่า `image`

ตอบกลับเป็นเลขทะเบียนตำรับยา ไม่ใช่รหัสของตาราง เพราะรหัสในฐานข้อมูลเป็นตัวเลข
แต่รหัสในไฟล์ข้อมูลฝั่งหน้าเว็บเป็นข้อความ การใช้เลขทะเบียนทำให้ตรงกันทั้งสองฝั่ง

```json
{ "found": true, "matchType": "reg_no", "regNos": ["1A 844/39"], "ocrText": "..." }
{ "found": false, "regNos": [] }
```

กรณีผิดพลาดให้ตอบด้วยรหัสสถานะ 4xx หรือ 5xx ไม่ใช่ 200 พร้อมข้อความแจ้งข้อผิดพลาด
เพื่อให้ฝั่งหน้าเว็บตรวจสอบจากรหัสสถานะได้

## ความคืบหน้า

**ส่วนติดต่อผู้ใช้งาน**

- หน้าหลัก กลุ่มอาการ ทางลัด และหน้าจอเปิดตัว
- ค้นหายาพร้อมคำแนะนำขณะพิมพ์ กรองตามกลุ่มอาการ และค้นด้วยเสียง
- หน้าข้อมูลยา แบ่งแท็บ หัวข้อพับ และอ่านออกเสียง
- หน้าถ่ายรูปฉลากยา เปิดกล้อง ถ่ายภาพนิ่ง เลือกภาพจากเครื่อง และแสดงผล 3 แบบ
- ปรับขนาดตัวอักษร 3 ระดับ โหมดสีเข้ม และรองรับการใช้งานด้วยแป้นพิมพ์

**ส่วนประมวลผล**

- เชื่อมฐานข้อมูล Neon และสร้างตารางครบทั้ง 7 ตาราง
- เส้นทางค้นหาและดูข้อมูลยา
- ทดสอบ Google Cloud Vision อ่านข้อความจากภาพได้แล้ว
- ตัวจับคู่ยา 3 ลำดับ ทดสอบผ่านแล้ว

## สิ่งที่ยังต้องทำ

**ส่วนประมวลผล**

1. ติดตั้ง `CORSMiddleware` มิฉะนั้นเบราว์เซอร์จะบล็อกทุกคำขอจากหน้าเว็บ
2. เพิ่มแพ็กเกจ `python-multipart` มิฉะนั้น FastAPI รับไฟล์ภาพไม่ได้
3. ทำเส้นทาง `/scan` ตามสัญญาข้างบน
4. เปลี่ยน `/medicines/{id}` ให้ตอบ 404 เมื่อไม่พบข้อมูล แทนการตอบ 200 พร้อมข้อความแจ้งข้อผิดพลาด
5. จัดรูปข้อความก่อนเทียบใน `matcher.py` โดยตัดสระบนล่าง วรรณยุกต์ ช่องว่าง และเครื่องหมายออก
   เนื่องจากการรู้จำอักขระภาษาไทยมักอ่านสระและวรรณยุกต์คลาดเคลื่อน
6. เพิ่มคอลัมน์ที่ฝั่งหน้าเว็บใช้แสดงผลแต่ฐานข้อมูลยังไม่มี

   | ตาราง | คอลัมน์ | ใช้ทำอะไร |
   |---|---|---|
   | `brand` | `packaging` | ยาเม็ดบรรจุแผงหรือยาน้ำบรรจุขวด ใช้เลือกไอคอน |
   | `brand` | `status` | ทะเบียนคงอยู่หรือยกเลิก ใช้เรียงลำดับและแสดงคำเตือน |
   | `brand` | `indications` `dosage_instructions` `dosage_adult` | เว้นว่างได้ ใช้กับ 5 ยี่ห้อที่ข้อมูลต่างจากสูตรตำรับกลาง |
   | `medicine` | `generic_th` `generic_en` | ชื่อสามัญทางยา คนละอย่างกับชื่อตัวยาสำคัญ |
   | `medicine` | `dosage_adult` | ขนาดยาสำหรับผู้ใหญ่ที่แสดงแยกช่อง |

**ส่วนติดต่อผู้ใช้งาน**

1. นำขึ้นใช้งานบน Vercel เพื่อให้ได้ที่อยู่แบบ HTTPS ซึ่งจำเป็นต่อการเรียกใช้กล้องบนมือถือ
2. เชื่อมเส้นทาง `/scan` โดยแก้ค่า `SCAN_API` ใน `js/app.js`
3. หน้าจัดการข้อมูลสำหรับผู้ดูแลระบบ รอระบบยืนยันตัวตนฝั่งประมวลผล
4. ทดสอบการเข้าถึงได้ ทั้งการใช้งานด้วยแป้นพิมพ์ โปรแกรมอ่านหน้าจอ และการขยายหน้าจอ

## ข้อตกลงของทีม

- ข้อมูลที่เก็บไว้ฝั่งหน้าเว็บ ไม่ต้องย้ายเข้าฐานข้อมูล ได้แก่ ไอคอน สีประจำกลุ่มอาการ
  ชื่อย่อกลุ่มอาการ ลำดับการเรียง และแหล่งอ้างอิงในหน้าเกี่ยวกับระบบ
  เนื่องจากเป็นเรื่องการแสดงผล ไม่ใช่ข้อมูลยา
- ข้อบ่งใช้เก็บเป็นข้อความก้อนเดียวตามฐานข้อมูล โดยคั่นแต่ละข้อด้วยการขึ้นบรรทัดใหม่
  แล้วให้ฝั่งหน้าเว็บแยกเอง
- ห้ามคอมมิตไฟล์ `.env` และไฟล์กุญแจของ Google ขึ้นกิตเด็ดขาด
- ห้ามใส่กุญแจการเข้าถึงบริการใด ๆ ไว้ในโค้ดฝั่งหน้าเว็บ เพราะผู้ใช้งานเปิดอ่านได้ทั้งหมด

## ข้อจำกัดความรับผิดชอบ

ระบบนี้เป็นเครื่องมือต้นแบบเพื่อการศึกษาและช่วยอ่านฉลากยาเท่านั้น ไม่ใช่คำแนะนำทางการแพทย์
ข้อมูลที่แสดงอาจไม่ตรงกับฉลากยาฉบับล่าสุดของผลิตภัณฑ์ โปรดอ่านฉลากจากผลิตภัณฑ์จริงเสมอ
และปรึกษาแพทย์หรือเภสัชกรก่อนใช้ยา
